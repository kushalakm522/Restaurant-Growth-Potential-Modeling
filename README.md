# Restaurant Growth Potential Modeling & Strategic Classification System

## Project Overview
This project analyzes restaurant performance data to explore growth potential and classify restaurants into High Growth, Medium Growth, and Low Growth categories using Python and machine learning.

## Objectives
- Analyze restaurant orders, revenue, and net profit.
- Compare restaurant segments and delivery channels.
- Identify important factors associated with growth categories.
- Build and evaluate a Random Forest classification model.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset
The project uses the SkyCity Auckland Restaurants & Bars dataset for exploratory data analysis and modeling.

## Machine Learning
A Random Forest Classifier is used to predict restaurant growth categories. In the current evaluation, the model achieved 49.12% accuracy without the Subregion feature. Further model validation and improvement may be needed.

## Project Structure
- `Restaurant_Growth_Potential_Modeling.ipynb` — project analysis and machine learning notebook.
- `SkyCity Auckland Restaurants & Bars.csv` — dataset, if permitted to share.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells in order.
